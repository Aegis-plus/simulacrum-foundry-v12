# Release packages

Built packages for the Foundry VTT v12 build of Simulacrum. Source is on [`main`](https://github.com/Aegis-plus/simulacrum-foundry-v12/tree/main).
This branch is rebuilt automatically on every release and keeps the newest 3 packages.

Install in Foundry with this manifest URL:

```
https://raw.githubusercontent.com/Aegis-plus/simulacrum-foundry-v12/main/module.json
```

| Package |
| --- |
| [simulacrum-1.1.4.zip](simulacrum-1.1.4.zip) |
| [simulacrum-1.1.3.zip](simulacrum-1.1.3.zip) |
| [simulacrum-1.1.2.zip](simulacrum-1.1.2.zip) |

`module.json` here is a copy of the manifest the newest package was built from.
